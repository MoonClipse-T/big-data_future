## 흐름 (약 20~25분)
1. 2026년 연구소 → 서기 2187년 폐허가 된 연구소, 바이러스 X에 감염된 환자 “하나”
2. **작전 1 · 유전체 수집**: 나노 로봇이 되어 혈관 벽을 걸으며 감염 세포 5곳에서 샘플 채취, 바이러스 40개 처치 (백혈구 회피)
3. **유전체 분석실**: 빅데이터의 양 → 보존 구역 찾기(비교할 유전체 수 슬라이더) → 유전형별 중증 위험 예측 → 데이터 공유 투표(사생활 침해)
4. **AI 신약 설계실**: 후보 100만 개 → 3개로 거르기 → 치료제 고르기
5. **작전 2 · 치료제 투입**: 감염 세포 6곳 치료, 면역 회복, 변이 바이러스 출현
6. 엔딩 · 연구 보고서 (활용 4가지 · 문제점 3가지)

## 조작 (1차시와 같음)
- 패드: 왼쪽 조이스틱 이동(끝까지 밀면 자동 가속) · 오른쪽 화면 끌기로 시점 · 노란 버튼 돌진 · 파란 버튼 위장막
- PC: WASD/방향키 · 마우스 끌기 · 스페이스/Shift 돌진 · E 위장막

- `?skip` 인트로 건너뛰기 · `?stage=2` 치료 작전부터 · `?teacher` 미션 완료 버튼 (PC는 Ctrl+Shift+N)
