# BIG DATA · FUTURE — 바이러스 X

통합과학 2 「과학 기술의 활용 – 빅데이터」 2차시 게임형 수업 (크로노스 프로토콜 미래 편)

- 플레이: https://moonclipse-t.github.io/big-data_future/
- 1차시 (과거 편): https://moonclipse-t.github.io/big-data_past/

## 흐름 (약 25분)
1. 2026년 연구소 → 서기 2187년 폐허가 된 연구소, 바이러스 X에 감염된 환자 “하나”
2. **작전 1 · 혈관**: 감염 세포 샘플 3개, 바이러스 25개 처치
   → **분석 ① 바이러스의 정체**: 유전체 조각 이어 붙이기 → 바이러스 데이터베이스 비교 → 바뀐 유전자 찾기 (원인: 박쥐 바이러스의 스파이크 변이)
3. **작전 2 · 심장**: 박동 때마다 조여드는 벽과 열리고 닫히는 판막. 심장 근육 세포 샘플 3개, 의료 데이터 노드 3개 수리
   → **분석 ② 누가 위험할까**: 데이터 정제 → 중증·경증 환자 비교(GWAS) → 하나의 위험 예측 → 데이터 공유 투표(사생활 침해)
4. **작전 3 · 뇌**: 신경 신호(전기) 피하기, 감염된 신경 세포 3곳 스캔
   → **분석 ③ 치료제 개발**: 표적 정하기 → AI 가상 실험(100만 → 3개) → 임상 시험 데이터(위약 비교)
5. **최종 작전**: 뇌의 감염된 신경 세포 3곳에 치료제 주입 (면역 세포가 우리 편)
6. 엔딩 · 연구 보고서 (활용 4가지 · 문제점 3가지)

## 과학 설정
- 바이러스는 스스로 움직이거나 늘어나지 못해요. 떠다니는 바이러스는 흐름에 실려 다닐 뿐이고, 건강한 세포에 닿으면 그 세포 안에서 복제돼요.
- 바이러스에 점령된 세포(**감염체**)가 움직이며 로봇을 들이받거나 바이러스 덩어리를 뿜어요. 쓰러뜨리면 안의 바이러스가 터져 나와요.
- 면역 세포 3종: 호중구(빠르게 덮침), 대식세포·미세아교세포(빨간 원 자리를 삼킴), B세포(항체 발사)

## 조작 (1차시와 같음)
- 패드: 왼쪽 조이스틱 이동(끝까지 밀면 자동 가속) · 오른쪽 끌기 시점 · **오른쪽 톡 = 레이저** · 노란 버튼 돌진 · 파란 버튼 위장막
- PC: WASD/방향키 · 마우스 끌기 시점 · **클릭 또는 F = 레이저** · 스페이스/Shift 돌진 · E 위장막
- 시점이 반대로 느껴지면 화면의 「시점 반전」 버튼 (패드마다 기억)

## 교사용 URL 옵션
- `?skip` 인트로 건너뛰기 · `?stage=heart` / `?stage=brain` / `?stage=cure` 해당 장소부터
- `?teacher` 미션 완료 버튼 (PC는 Ctrl+Shift+N) · `?touch` / `?mouse` 조작 방식 강제
- 대사·질문은 `content.js`, 분석실 데이터는 `analysis.js`에서 고칠 수 있어요.
